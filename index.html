Server API Access
Self-Healing Dynamic API Bridge v2.0 is running on http://127.0.0.1:8000. Below are all available API endpoints.
GET /api/health Server health & status GET /api/server-time Current server time (IST) GET /api/metrics System metrics & statistics GET /api/chaos-status Chaos state & audit logs GET /api/pipeline-status Pipeline topology & nodes GET /api/simulate-random Random healing scenario GET /api/bridge-request Self-healing bridge call GET /api/direct-upstream Direct call (no bridge)
POST /api/toggle-chaos Switch chaos mode
POST /api/heal-payload Heal custom payload
POST /api/pipeline-trigger-failure Trigger pipeline failure
POST /api/pipeline-reset Reset pipeline state

Quick Start

$ python server.py
$ curl http://127.0.0.1:8000/api/health
$ curl http://127.0.0.1:8000/api/metrics
$ curl -X POST http://127.0.0.1:8000/api/heal-payload \
  -H "Content-Type: application/json" \
  -d '{"payload":{"client_name":"John","mail_address":"j@x.com"}}'
